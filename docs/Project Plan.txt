Standard module development lifecycle
1. M1 — Requirements
   Define business objectives, workflows, policies, user roles, and acceptance criteria.

2. M2 — Functional design   
   Define screens, user journeys, validations, and expected behavior.

3. M3 — Database design  
   Define schemas, tables, relationships, constraints, functions, and RLS requirements.

4. M4 — Backend development & testing
   Implement business logic, database operations, and API/server actions, validation rule & message.

5. M5 — Frontend development & testing
   Implement pages, forms, tables, dialogs, and interactions.

6. M6 — UAT
   Test business scenarios, permissions, data integrity, and edge cases.

7. M7 — Deployment
   Deploy the module to the test environment and verify actual workflows.

8. M8 — Completion and documentation
   Record decisions, schema changes, test results, and known limitations.
